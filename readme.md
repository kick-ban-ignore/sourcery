# Sourcery - Quellenübersicht

A minimalistic Streamlit web application for managing and filtering scientific sources during your PhD Research or other adventures.

Just upload CSV files containing your research Sources, then filter data.

Preview can be tested <a href="https://sourcery-eqz8smm4aysnmutr4vkt63.streamlit.app/" target="_blank" rel="noopener noreferrer">here on Streamlit</a>.
Test data can be found <a href="https://github.com/kick-ban-ignore/sourcery/blob/main/data.csv" target="_blank" rel="noopener noreferrer"> here on Github.

## How to Use

1. Prepare a CSV file with your research sources
2. Run the app: `streamlit run app.py`
3. Upload your file
6. View and explore the magic

## Requirements

- Python 3.7+
- Streamlit
- Pandas

Install dependencies:
```
pip install streamlit pandas
```
